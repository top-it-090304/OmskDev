# Changelog - Система артефактов и уровней

## 2026-04-16 - Полная система артефактов и прогрессии

### ✨ Новые возможности

#### 🎒 Система рюкзака (Backpack)
- Сетка отображения собранных артефактов в стиле The Binding of Isaac
- 4 колонки с автоматическим переполнением вниз
- Иконки 32x32 пикселя с анимацией появления
- Tooltip с названием и описанием при наведении
- Расположен в правом верхнем углу UI

#### 📦 31 артефакт с 4 уровнями редкости
- **🟠 Legendary (2):** Golden Cup, Uno Reverse Card
- **🟣 Epic (5):** Disco Ball, Fairy Bottle, Golden Ball, Top Hat, Electronic Key
- **🔵 Rare (9):** Metal Shield, Crown, Blue Shroom, Injector, Clock, Red Potion, Diamond, Old Book, Coffee Mug
- **🟢 Common (15):** Bottle, Pill, Button, Letter, Waffle, Juice Box, Ramen Bowl, Milk Box, Lime Juice, Pill Can, Small Cactus, Snow Ball, Bongo, Flashlight, VHS Cassette

#### 📊 Система уровней
- Получение опыта от убийства врагов
- Прогресс-бар опыта в UI
- Повышение характеристик при level up
- Popup уведомление "LEVEL UP!"
- Множитель опыта от артефактов (Golden Cup, Uno Reverse Card)

#### 💬 Popup система для артефактов
- Красивое всплывающее окно при подборе
- Название артефакта золотым цветом (32px)
- Цветовая кодировка бонусов:
  - 🟢 Зеленый - скорость
  - 🔴 Красный - здоровье
  - 🟠 Оранжевый - урон
  - 🔵 Синий - специальные эффекты
- Анимация появления и исчезновения
- Автоматически пропадает через 3 секунды
- z-index 4096 для отображения поверх всего

### 🔧 Технические улучшения

#### Базовый класс ArtefactPickup
- Универсальная система с экспортируемыми параметрами
- Автоматическое получение иконки из Sprite2D
- Поддержка базовых бонусов и бонусов за уровень
- Метод `custom_effect()` для уникальных эффектов
- Анимация покачивания на земле
- Размер увеличен в 4 раза (scale 3.2x)
- CollisionShape2D radius 60 для удобного подбора

#### Система опыта
- Множитель опыта сохраняется в `GameConstants.PLAYER_EXP_MULTIPLIER_BONUS`
- Формула: базовый_опыт * множитель
- Множители стакаются (Golden Cup x1.2 + Uno Reverse x1.5 = x1.8)
- Награды за врагов:
  - Goblin Axe: 20 EXP (было 15)
  - Skeleton Bow: 18 EXP (было 12)
  - Beast Goblin: 50 EXP

#### Интеграция
- Backpack добавлен в `World/layer.tscn` в UI слой
- UI слой имеет группу "ui_layer" для поиска
- Все артефакты автоматически добавляются в MapManager
- ExpBar показывает прогресс опыта и текущий уровень

### 🎮 Геймплейные особенности

#### Легендарные артефакты
- **Golden Cup:** +2 ко всем характеристикам за уровень, +20% к опыту
- **Uno Reverse Card:** x1.5 ко всем текущим характеристикам, +50% к опыту
  - Стратегия: подбирать в конце игры для максимального эффекта

#### Рекомендуемые билды
- **Танк:** Metal Shield, Crown, Red Potion, Ramen Bowl, Top Hat
- **Скорость:** Coffee Mug, Blue Shroom, Old Book, Lime Juice, Electronic Key
- **Урон:** Diamond, Injector, Golden Ball, Clock, Fairy Bottle
- **Универсал:** Golden Cup, Disco Ball, Uno Reverse Card, Electronic Key
- **Фарм опыта:** Golden Cup + Uno Reverse Card = x1.8 к опыту
