## 🎯 ФУНКЦИОНАЛ

### ✅ Новая игра
При нажатии кнопки "Новая игра":
1. Все характеристики сбрасываются к базовым значениям
2. Старое сохранение удаляется
3. Игра запускается с чистого листа

### ✅ Продолжить
При нажатии кнопки "Продолжить":
1. Загружаются все сохраненные характеристики
2. Восстанавливается уровень игрока и опыт
3. Восстанавливается текущее здоровье
4. Восстанавливается позиция игрока (опционально)
5. Игра продолжается с того же места

### ✅ Выход в главное меню
При выходе в главное меню через паузу:
1. Автоматически сохраняются все данные
2. Сохраняется текущее состояние игрока
3. Игра возвращается в главное меню

---

## 📁 СТРУКТУРА ФАЙЛОВ

### `globals/save_system.gd`
Автозагружаемый синглтон для управления сохранениями.

**Основные функции:**
- `save_game()` - Сохранить текущее состояние игры
- `load_game()` - Загрузить сохраненное состояние
- `reset_to_base_values()` - Сбросить все к базовым значениям
- `has_save()` - Проверить наличие сохранения
- `delete_save()` - Удалить файл сохранения
- `restore_player_state()` - Восстановить состояние игрока после загрузки

### Измененные файлы:
- `World/UI/newgame.gd` - Кнопка "Новая игра"
- `World/UI/continue_button.gd` - Кнопка "Продолжить"
- `World/UI/paused.gd` - Меню паузы
- `World/UI/menu.tscn` - Главное меню
- `project.godot` - Добавлен autoload SaveSystem

### Прогрессия игрока:
```gdscript
- PLAYER_LEVEL (уровень)
- PLAYER_EXPERIENCE (опыт)
- PLAYER_BASE_EXP_TO_LEVEL (базовый опыт для уровня)
- PLAYER_EXP_MULTIPLIER (множитель опыта)
```

### Прогресс в игре:
```gdscript
- ENEMIES_KILLED (убито врагов)
- ROOMS_CLEARED (зачищено комнат)
- ENEMY_LEVEL (уровень врагов)
```

### Текущее состояние:
```gdscript
- player_current_health (текущее здоровье)
- player_position (позиция игрока)
  - x, y (координаты)
  - room_x, room_y (комната)
```

## 📂 РАСПОЛОЖЕНИЕ СОХРАНЕНИЯ

**Путь:** `user://save_game.dat`

**Реальный путь на Windows:**
```
C:\Users\<Username>\AppData\Roaming\Godot\app_userdata\Dungeon\save_game.dat
```

**Формат:** JSON (читаемый текстовый формат)

**Пример содержимого:**
```json
{
	"version": "1.0",
	"timestamp": 1713334270,
	"player_stats": {
		"max_speed": 250,
		"max_health": 2500,
		"attack_damage": 25,
		...
	},
	"player_progression": {
		"level": 5,

	"player_position": {
		"x": 1234.5,
		"y": 678.9,
		"room_x": 4,
		"room_y": 4
	}
```

## 🎮 ИСПОЛЬЗОВАНИЕ

### Для игрока:

1. **Начать новую игру:**
   - Нажать "Новая игра" в главном меню
   - Все прогресс сбрасывается
   - Старое сохранение удаляется

2. **Продолжить игру:**
   - Кнопка активна только если есть сохранение
   - Нажать "Продолжить" в главном меню
   - Игра загружается с того же места

3. **Сохранить прогресс:**
   - Нажать ESC (пауза)
   - Выбрать "Выход в главное меню"
   - Игра автоматически сохранится

### Для разработчика:

```gdscript
# Сохранить игру вручную
SaveSystem.save_game()

# Загрузить игру
if SaveSystem.load_game():
    print("Игра загружена")

# Проверить наличие сохранения
if SaveSystem.has_save():
    print("Сохранение существует")

# Сбросить к базовым значениям
SaveSystem.reset_to_base_values()

# Удалить сохранение
SaveSystem.delete_save()

# Восстановить состояние игрока (вызывать после загрузки сцены)
SaveSystem.restore_player_state()
```

## ⚠️ ИЗВЕСТНЫЕ ОГРАНИЧЕНИЯ

1. **Не сохраняются:**
   - Собранные артефакты (TODO)
   - Состояние карты (какие комнаты пройдены)
   - Позиции врагов
   - Состояние дверей

2. **Позиция игрока:**
   - Сохраняется, но может быть некорректной при загрузке
   - Рекомендуется доработать систему комнат для точного восстановления

3. **Артефакты:**
   - Эффекты артефактов сохраняются в характеристиках
   - Но список собранных артефактов не сохраняется
   - Рюкзак будет пустым после загрузки
