# docs/screenshots/

Сюда кладут картинки и короткое видео для корневого `README.md`.

**Не кладите файлы в корень проекта** (рядом с `README.md`) — только в эту папку.

## Имена файлов

| Имя файла | Что показать | Формат | Размер (ориентир) |
|-----------|--------------|--------|-------------------|
| `hero.png` | главный кадр в шапке README | PNG | до 1–2 МБ |
| `gameplay.gif` | 5–15 сек. геймплея | GIF | до ~20 МБ (у вас ~17 МБ — ок) |
| `gameplay.mp4` | альтернатива GIF | MP4 | до 10 МБ |
| `gameplay.png` | статичный кадр вместо ролика | PNG | до 1 МБ |
| `minimap.png` | миникарта | PNG | до 1 МБ |
| `boss.png` | бой с боссом | PNG | до 1–2 МБ |
| `coop.png` | кооператив | PNG | до 1–2 МБ |
| `menu.png` | меню / лобби | PNG | до 1–2 МБ |

Если файла нет — блок в README на GitHub просто не отобразится.

## Размер GIF

| Размер | Можно в git? |
|--------|----------------|
| до ~20 МБ | да, нормально для README |
| 50–100 МБ | технически возможно, но тяжело для клонирования |
| больше 100 МБ | GitHub отклонит push |

GIF **~17 МБ** — подходит, сохраните как `gameplay.gif` в эту папку.

### Сжать GIF или видео в MP4 (ffmpeg)

Установите [ffmpeg](https://ffmpeg.org/download.html), затем в PowerShell:

```powershell
# Из большого GIF → короткий MP4 (~5–15 МБ)
ffmpeg -i "C:\путь\к\вашему.gif" -movflags faststart -pix_fmt yuv420p -vf "scale=1280:-2" -t 15 docs/screenshots/gameplay.mp4

# Из записи экрана (MP4/MKV) — обрезать и сжать
ffmpeg -i "C:\путь\к\записи.mp4" -t 12 -vf "scale=1280:-2" -c:v libx264 -crf 28 -an docs/screenshots/gameplay.mp4
```

- `-t 15` — только первые 15 секунд.
- `-crf 28` — сильнее сжатие (чем больше число, тем меньше файл; 23–28 обычно нормально).

### Если всё же нужен маленький GIF

Только для роликов **до ~5 МБ** и **до 10–15 секунд**. ScreenToGif → Export → уменьшить FPS (10–15) и размер кадра (480–720 px по ширине).

## Как добавить картинки (пошагово)

1. Сделайте скриншот в игре (`Win + Shift + S` или `Print Screen`).
2. Сохраните файл в **`D:\Games\game\docs\screenshots\`** с именем из таблицы выше (например `menu.png`).
3. Проверьте: `Get-ChildItem docs\screenshots`
4. Закоммитьте:
   ```bash
   git add docs/screenshots/
   git commit -m "docs: add screenshots"
   git push
   ```

## Сжатие PNG

[tinypng.com](https://tinypng.com) или `pngquant` — обычно в 3–5 раз меньше без заметной потери качества.
