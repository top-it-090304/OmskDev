## Базовый класс ArtefactPickup

Все артефакты наследуются от `artefact_pickup.gd`, который предоставляет:

### Экспортируемые параметры:
```gdscript
# Базовая информация
@export var artefact_name: String
@export var artefact_icon: Texture2D
@export var artefact_description: String

# Бонусы к характеристикам
@export var speed_bonus: int = 0
@export var health_bonus: int = 0
@export var damage_bonus: int = 0

# Бонусы за уровень
@export var health_per_level_bonus: int = 0
@export var speed_per_level_bonus: int = 0
@export var damage_per_level_bonus: int = 0
```

### Особенности:
- ✅ Автоматическое получение иконки из Sprite2D
- ✅ Анимация покачивания на земле
- ✅ Анимация подбора (увеличение и исчезновение)
- ✅ Автоматическое добавление в рюкзак
- ✅ Подробный вывод в консоль при подборе
- ✅ Метод `custom_effect()` для уникальных эффектов
- ✅ **Popup с отображением повышения характеристик** - при подборе артефакта появляется красивое окно с названием и списком всех бонусов

## Как создать новый артефакт

1. Создайте скрипт, наследующий `artefact_pickup.gd`:
```gdscript
extends "res://scene/pick_up/artefacts/artefact_pickup.gd"

func _ready():
    artefact_name = "Название"
    artefact_description = "Описание"
    speed_bonus = 10  # или другие бонусы
    super._ready()
```

2. Создайте сцену:
```
Node2D (ваш скрипт)
├── Area2D (collision_mask = 9)
│   └── CollisionShape2D (CircleShape2D, radius = 20)
└── Sprite2D (текстура из 40 Random Items)
```

3. Подключите сигнал `area_entered` к методу `_on_area_2d_area_entered`

4. Готово! Артефакт автоматически работает с системой рюкзака

## Размещение артефактов на карте

Просто добавьте сцену артефакта в любую комнату или уровень. При соприкосновении с игроком артефакт:
1. Применит свои эффекты
2. Добавит иконку в рюкзак
3. Исчезнет с анимацией

## Комбинации артефактов

Артефакты можно комбинировать для создания уникальных билдов:
- **Танк:** Metal Shield + Crown + Red Potion
- **Скорость:** Coffee Mug + Blue Shroom + Old Book
- **Урон:** Diamond + Injector + Clock
- **Универсал:** Golden Cup + любые другие артефакты

## Система Popup

При подборе артефакта автоматически появляется красивое всплывающее окно (`artefact_popup.tscn`), которое показывает:
- Название артефакта (золотым цветом)
- Список всех бонусов с цветовой кодировкой:
  - 🟢 Зеленый - бонусы к скорости
  - 🔴 Красный - бонусы к здоровью
  - 🟠 Оранжевый - бонусы к урону
  - 🔵 Синий - специальные эффекты (множитель опыта и т.д.)

Popup автоматически исчезает через 3 секунды с плавной анимацией.

### Добавление кастомных эффектов в popup

Если вы создаете артефакт с уникальным эффектом, добавьте информацию в popup через `stat_changes`:

```gdscript
func custom_effect() -> void:
    # Ваш эффект
    GameConstants.SOME_STAT += 10
    
    # Добавляем в popup
    stat_changes.append({
        "text": "Описание эффекта", 
        "color": Color(1, 1, 0)  # Желтый цвет
    })
```

## Множитель опыта

Golden Cup увеличивает получаемый опыт на 20% (множитель x1.2). Этот эффект:
- Сохраняется в `GameConstants.PLAYER_EXP_MULTIPLIER_BONUS`
- Применяется ко всему получаемому опыту
- Можно комбинировать несколько Golden Cup для еще большего бонуса (x1.44, x1.728 и т.д.)
